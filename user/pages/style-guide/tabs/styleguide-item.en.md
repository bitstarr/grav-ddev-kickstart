Content areas with tab-based navigation. Each tab shows a title in the tab bar and contains a complete content block. Without JavaScript, the content of all tabs is displayed one below another.

## Fields 

| Field | Type | Note |
|---|---|---|
| **Title** | Text | Heading of the section |
| **Hide heading** | Yes/No |  Heading is not output |
| **Published** | Yes/No | Visibility of the module |

## Fields per entry

| Field | Type | Description |
|---|---|---|
| **Title** | Text | Label in the tab bar |
| **Content** | Markdown | Tab content |
