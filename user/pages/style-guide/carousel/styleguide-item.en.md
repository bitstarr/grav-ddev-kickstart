An image carousel.

## Fields 

| Field | Type | Note |
|---|---|---|
| **Title** | Text | Not displayed, helps with orientation in the admin |
| **Page media** | | Upload your images here |
| **Configure carousel** | Items | Add entries, select an image and sort them |
| **Image width** | Number | If all images should have the same width, otherwise leave at `0` |
| **Image height** | Number | Sets the height of the images and thus of the element, default `500` |
| **Published** | Visibility of the module |
