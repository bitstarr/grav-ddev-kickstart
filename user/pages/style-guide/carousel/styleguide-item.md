Ein Bilder-Karusell.

## Felder 

| Feld | Typ | Bemerkung |
|---|---|---|
| **Titel** | Text | Wird nicht angezeigt, hilft der Orientierung im Admin |
| **Seiten-Medien** | | Hier lädst du die Bilder hoch |
| **Karussell konfigurieren** | Elemente | Einträge hinzufügen, Bild auswählen und sortieren |
| **Bildbreite** | Zahl | Wenn alle Bilder dieselbe Breite haben sollen, sonst bei `0` belassen |
| **Bildhöhe** | Zahl | Legt Höhe der Bilder und damit des Elements fest, Standard `500` |
| **Veröffentlicht** | Ja/Nein | Sichtbarkeit des Moduls |
