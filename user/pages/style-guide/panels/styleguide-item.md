Zweispaltiger Block, der sich ein wenig an Comic-Panels orientiert. Du kannst 3 Bilder kombinieren, wobei ein Bild sehr groß und quadratisch dargestellt wird.

## Felder

| Feld | Typ | Bemerkung |
|---|---|---|
| **Überschrift** | Text | Wird nicht angezeigt, hilft der Orientierung im Admin |
| **Seiten-Medien** | Seiten-Medien | Die Bilder des Panels — Reihenfolge ist per Drag & Drop sortierbar, das erste Bild wird immer groß dargestellt |
| **Position des großen Bild** | Auswahl | Links/Rechts/Oben/Unten, Standard: Links |
| **Ausbreitung** | Auswahl | Wie viel Platz nimmt das Element ein? |
| **Veröffentlicht** | Ja/Nein | Sichtbarkeit des Moduls |

### Erläuterung zu Ausdehnung

| Option | Auswirkung |
|---|---|
| Standard | Element ist so breit wie normaler Content (Wrapper) |
| Breiter | Element steht etwas über den Content-Wrapper heraus, um visuelle Spannung zu erzeugen |
| Volle Breite | Element geht über die gesamte Bildschirmbreite. Texte haben trotzdem einen Mindestabstand zum Bildschirmrand |
