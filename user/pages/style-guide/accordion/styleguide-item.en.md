Expandable list items for structured content such as FAQs or service descriptions. Each entry shows a title and can be expanded to reveal the explanatory text.

## Fields 

| Field | Type | Note |
|---|---|---|
| **Title** | Text | Heading of the section |
| **Hide heading** | Yes/No |  Heading is not output |
| **Published** | Yes/No | Visibility of the module |

## Fields per entry

| Field | Type | Note |
|---|---|---|
| **Title** | Text | Heading of the entry |
| **Content** | Markdown | Explanatory text |
