Displays the description as a quote and the short description as the author on a full-width, brand-colored area.

## Fields

| Field name | Type | Note |
| --- | --- | --- |
| **Title** | Text | Not displayed, helps with orientation in the admin |
| **Editor** | Markdown | Quote text |
| **Name** | Text | Author |
| **Job/Title/Position** | Text | Position/expertise |
| **Portrait** | Selection | optional, 1 graphic from the page media |
| **Portrait position** | Selection | Before quote (desktop: left), after quote (desktop: right) |
| **Published** | Yes/No | Visibility of the module |
