Zeigt die Beschreibung als Zitat und die Kurzbeschreibung als Autor auf einer markenfarbigen Fläche in voller Breite an.

## Felder

| Feldname | Typ | Bemerkung |
| --- | --- | --- |
| **Titel** | Text | Wird nicht angezeigt, hilft der Orientierung im Admin |
| **Editor** | Markdown | Zitattext |
| **Name** | Text | Autor/in |
| **Job/Titel/Position** | Text | Position/Expertise |
| **Portrait** | Auswahl | optional, 1 Grafik aus den Seitenmedien |
| **Portrait Position** | Auswahl | Vor Zitat (Desktop links), Nach Zitat (Desktop rechts) |
| **Veröffentlicht** | Ja/Nein | Sichtbarkeit des Moduls |
