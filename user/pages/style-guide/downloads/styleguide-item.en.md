Expandable list items for structured content such as FAQs or service descriptions. Each entry shows a title and can be expanded to reveal the explanatory text.

## Fields 

| Field | Type | Note |
|---|---|---|
| **Title** | Text | Heading of the section |
| **Hide heading** | Yes/No |  Heading is not output |
| **Display** | Selection | The detailed display shows a preview image and a description |
| **Published** | Yes/No | Visibility of the module |

## Fields per entry

| Field | Type | Note |
|---|---|---|
| **Title** | Text | Heading/label of the entry |
| **File** | Media selection | File for download |
| **Description** | Text | Information about the file, visible in the detailed display |
| **Alternative preview image** | Media selection | Useful for PDF, video, etc. Visible in the detailed display |
