A callout element to highlight up to three topics. Currently more of a proof of concept that can be adapted to the needs of individual projects.

## Fields 

| Field | Type | Note |
|---|---|---|
| **Title** | Text | Heading of the section |
| **Hide heading** | Yes/No |  Heading is not output |
| **Invert** | Yes/No | Display element with a colored background |
| **Published** | Yes/No | Visibility of the module |

## Fields per entry

| Field | Type | Note |
|---|---|---|
| **Text** | Text | Heading/name of the entry |
| **URL** | Text | Link target |
| **Icon** | Selection | optional, from [icon list](../icons) |
